# 終活かんたん診断

はい・いいえを選ぶだけで、約5分で「今のあなたに必要な終活の準備」がわかる無料の簡易診断です。
個人情報の入力は不要です。

**▶ 診断をはじめる：https://directfuneral.github.io/kantansindan/**

---

## この診断でわかること

全24問前後（回答内容により一部の質問は省略されます）、5つのステップで終活の現状を確認します。

| STEP | 内容 |
|---|---|
| 1 | ご家族・身寄り |
| 2 | 財産 |
| 3 | 医療・介護・葬儀 |
| 4 | デジタル・身の回り |
| 5 | お気持ち |

回答後、次の内容が「終活カルテ」としてその場で表示されます。

- **対策の緊急度**（10段階）と、その主な理由
- **分野別の状態**（要対策・要確認・良好）
- **優先して取り組みたい準備 トップ3**と、まず何をすればよいか
- **ご不安へのアドバイス**（選んだ不安ごとの具体的なヒント）

結果は「診断結果」と「処方箋」の2枚に分けて、印刷またはPDF保存ができます。

## より詳しく準備したい方へ

診断結果をもとに、実際の書面づくりまで進めたい方は「終活リーガルクリニック」をご利用ください（利用無料・専門家監修）。

**▶ 終活リーガルクリニック：https://directfuneral.github.io/dai8legalclinic/**

エンディングノート、相続関係図、財産目録の作成や、医療・介護の希望の整理ができます。

## プライバシーについて

- お名前・ご住所などの入力はありません。
- ご回答内容はお使いの端末の中だけで処理され、**保存・送信されることはありません**。
- 画面を閉じると回答内容は消えます。

## 管理用メモ

### ファイル構成

```
index.html   … アプリ本体（HTML・CSS・JavaScript・画像をすべて1ファイルに収録）
README.md    … このファイル
```

外部ライブラリや外部への通信はありません。`index.html` 1つで動作します。

### 更新のしかた

1. 手元で `index.html` を修正し、ブラウザで動作を確認する
2. GitHubのリポジトリで「Add file」→「Upload files」から、同じ名前で上書きアップロード
3. 「Commit changes」を押す（反映まで数分かかります）

### ⚠ 重要：GitHub上で直接編集しないこと

`index.html` にはセキュリティ設定（CSP：Content-Security-Policy）が入っており、
`<style>` と `<script>` の中身をハッシュ値（内容の指紋のようなもの）で照合しています。

- スタイルやスクリプトを**1文字でも変更すると、ハッシュ値が合わなくなり画面が崩れます**。
- 修正したときは、`<head>` 内の CSP の `sha256-…` の値も新しい内容に合わせて更新してください。
- GitHub上の編集画面（鉛筆マーク）での直接修正は避け、手元で修正・確認してからアップロードしてください。
